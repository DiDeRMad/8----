# SuperGame

Начальный прототип онлайн-игрушки, построенный на стеке TypeScript + Express + Socket.IO (сервер) и обычный HTML/JS (клиент). Цель — постепенно развивать до полнофункционального многопользовательского проекта.

## Быстрый старт

1. Установите зависимости:
   ```bash
   cd supergame/server && npm install
   ```
2. Запустите сервер в режиме разработки:
   ```bash
   npm run dev
   ```
3. Откройте `supergame/client/index.html` в браузере (или поднимите любой статический сервер).

Сервер будет слушать порт `3000` по умолчанию. Клиент подключается к нему через WebSocket (Socket.IO).

## Структура репозитория

```
supergame/
├── client/          # фронтенд (пока статический HTML/JS, затем React)
└── server/          # TypeScript-сервер на Express + Socket.IO
```
